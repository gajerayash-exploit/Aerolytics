One engine, from rotor to report.

03 / Data integrity

Simulated data never passes as real.

Drone media often loses its GPS metadata. Aerolytics can still map the mission, and it labels every value with where it came from.

Live GPS

Streamed from the aircraft. RTK-grade where the hardware supports it.

EXIF

Read from the image file. As accurate as the drone's own GPS.

Manifest

Matched to a planned flight path. Positions are approximate.

Simulated

Generated for demonstration. Never shown as a field measurement.
